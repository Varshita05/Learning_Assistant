# React Client

This Vite application is the maintained Learning Assistant client. It calls the FastAPI backend at `http://localhost:8000` by default. Set `VITE_API_URL` to override the API origin.

From this directory:

```powershell
npm install
npm run dev
npm test
npm run lint
npm run build
```

The study endpoint shapes and local setup are documented in the repository [README](../README.md) and [runbook](../docs/05-runbook.md).
